## EZPKG -- Easy Package Installer for noobs

## **THIS IS NOT A PACKAGE MANAGER**

EZPKG is a TUI package installer written in python that makes installing packages easy 

--- 

EZPKG intends to make distros like arch easy for new linux users who want those stunning setups without the hassle

**FEATURES** 
- Easy visual install 
- Low resource usage
- Terminal based 
- Multi-repo categories e.g flatpak, AUR, etc
